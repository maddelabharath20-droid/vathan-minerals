## 📚 Categorized Agent Intelligence Directory

### 1. Frameworks & Multi-Agent Orchestrators
* **[OpenClaw](https://github.com/openclaw/openclaw)**: Persistent, proactive personal AI agents with multi-channel messaging, cron scheduling, and subagent spawning.
* **[AG2 / AutoGen](https://github.com/ag2ai/ag2)**: Multi-agent conversation framework for distributed problem-solving.
* **[CrewAI](https://github.com/crewAIInc/crewAI)**: Role-playing autonomous AI agent teams with defined goals and processes.
* **[MetaGPT](https://github.com/FoundationAgents/MetaGPT)**: Multi-agent software company emulation (PRD -> Design -> Tasks -> Code -> CI).
* **[Mastra](https://github.com/mastra-ai/mastra)**: Opinionated TypeScript framework for building production AI applications.
* **[Swarm](https://github.com/openai/swarm)**: Lightweight, ergonomic multi-agent orchestration.
* **[SandBase Harness](https://github.com/sandbaseai/sandbase-harness)**: Local-first managed agent runtime with persistent sessions and human approval gates.

### 2. Testing, Evaluation & Observability
* **[Arize-Phoenix](https://github.com/Arize-ai/phoenix)**: Open-source agent testing, evaluation, and OpenTelemetry observability.
* **[ClawMetry](https://github.com/vivekchand/clawmetry)**: Zero-config real-time observability dashboard for AI agent runtimes and token analytics.
* **[Latitude](https://github.com/latitude-dev/latitude-llm)**: Traces agent execution, clusters production failures, and auto-generates test evaluations.
* **[agent-qa](https://github.com/vostride/agent-qa)**: Self-improving QA harness for web and mobile end-to-end testing with regression detection.

### 3. Software Development & Autonomous Coding
* **[OpenHands](https://github.com/OpenHands/OpenHands)** (formerly OpenDevin): Autonomous software development platform for agentic code modifications.
* **[Aider](https://github.com/Aider-AI/aider)**: Terminal-based AI pair programming harness with git diff integration.
* **[GPT Pilot](https://github.com/Pythagora-io/gpt-pilot)**: Real-time pair-programmer and step-by-step application builder.
* **[Devika](https://github.com/stitionai/devika)**: Agentic software engineer executing high-level tasks through iterative research and code generation.

### 4. Agent Memory & Context Optimization
* **[Cortex Memory](https://github.com/sopaco/cortex-mem)**: Complete agent memory solution featuring extraction, vector indexing, and automated optimization.
* **[Agentic Context Engine](https://github.com/kayba-ai/agentic-context-engine)**: Self-improving agents that curate their own context based on execution feedback.
* **[Agentset](https://github.com/agentset-ai/agentset)**: Production RAG platform with hybrid search and multimodal reasoning.

### 5. Browser Automation & Tool Execution
* **Model Context Protocol (MCP)**: Standardized protocol connecting AI agents to local/remote database and API tools.
* **Browser Automation Agents**: Playwright and Chrome DevTools Protocol harnesses for automated headless verification.
